# Trainingo sound assets

Generated effect sounds for the Flutter Trainingo app.

- click.mp3: button/choice click
- correct.mp3: correct answer
- wrong.mp3: wrong answer
- complete.mp3: level complete
- grading_complete.mp3: grading finished
- code_success.mp3: code/test success
- code_fail.mp3: code/test failure
- soft_alert.mp3: soft feedback alert
